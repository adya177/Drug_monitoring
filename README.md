# Drug Monitoring

Jupyter notebook for exploratory analysis and machine-learning estimates for vancomycin, gentamicin, and phenytoin concentrations.

[![Launch on Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/adya177/Drug_monitoring/HEAD?labpath=Drug_monitoring.ipynb)

## Launch in your browser

Click **Launch on Binder** to open the notebook in a temporary JupyterLab session. The first launch may take a few minutes while Binder builds the environment. The dataset is not stored in this public repository; obtain the CSV from Kaggle and upload it when the notebook prompts you. Restarting the Binder session clears uploaded files.

## Run the notebook

1. Install the packages in `requirements.txt` (or use the Binder launch link above).
2. Obtain the dataset referenced in the first data-loading cell from Kaggle.
3. Open `Drug_monitoring.ipynb`, upload the CSV when prompted, and run the cells.

The notebook is published without saved cell outputs so it does not expose the local sample rows or embedded result plots. This repository contains the analysis notebook, not a hosted web application.
